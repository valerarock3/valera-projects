# 🎓 Платформа онлайн-курсов

Сайт курсов с регистрацией, админкой и оплатой. База данных — MySQL.

## Запуск

```powershell
# 1. Убедитесь, что MySQL запущен (см. ниже)
# 2. Запустите сайт
powershell -ExecutionPolicy Bypass -File run_courses.ps1
# или вручную:
node server.js
```

Сайт: **http://localhost:3001**

## 1. Как подключиться к базе данных

Подключение настроено в **`db.js`** (строки 1–10):

```js
const pool = mysql.createPool({
  host: "localhost",       // адрес сервера MySQL
  user: "app",             // пользователь приложения
  password: "app_password",// пароль пользователя
  database: "courses_db",  // имя базы данных
  connectionLimit: 10,     // размер пула соединений
  charset: "utf8mb4_unicode_ci",
});
```

Чтобы изменить подключение — отредактируйте эти поля.

### Прямое подключение из консоли (проверка/ручной доступ)

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" -u app -papp_password courses_db
```

### Создание БД и пользователя (если настраиваете с нуля)

```sql
CREATE DATABASE courses_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'app'@'localhost' IDENTIFIED BY 'app_password';
GRANT ALL PRIVILEGES ON courses_db.* TO 'app'@'localhost';
FLUSH PRIVILEGES;
```

### Схема БД (связанные таблицы)

```
users       1 ──── N   enrollments   N ──── 1   courses
users       1 ──── N   reviews       N ──── 1   courses
courses     1 ──── N   lessons                  (удаление курса → каскадное удаление уроков)
users       1 ──── N   payments      N ──── 1   courses
courses     N ──── 1   categories               (категория удаляется → courses.category_id = NULL)
```

Таблицы создаются автоматически при запуске сервера (функция `initSchema()` в `db.js`).

## 2. Тёмная и светлая тема

Кнопка 🌙/☀ в шапке переключает тему. Выбор сохраняется в `localStorage` и применяется через CSS-переменные в `style.css`:

```css
:root { /* тёмная (по умолчанию) */ --bg: #0d1520; }
:root[data-theme="light"] { --bg: #f2f6fa; }
```

## 3. Перевод на английский

Кнопка 🇷🇺/🇬🇧 в шапке переключает язык интерфейса. Словари в `public/translations.js`. Тексты интерфейса используют `data-i18n` атрибуты и функцию `t("ключ")`. Данные курсов (названия, уроки) хранятся в БД и не переводятся.

## 4. Оплата курсов

- Платные курсы → при записи открывается модальное окно оплаты картой (демо, деньги не списываются).
- Оплата подтверждается SMS-кодом (демо: код показывается на экране, в реальном проекте — отправка на телефон).
- После подтверждения создаётся запись в `payments` и запись на курс в `enrollments`.
- Бесплатные курсы → запись без оплаты.
- Список оплат виден админу во вкладке «💳 Оплаты».

## 5. Уроки, тесты и медиа

- Урок может содержать текст, изображение, видео (свой файл или YouTube) и аудио.
- К уроку можно прикрепить тест (формат: вопросы с новой строки, варианты с `-`, правильный — с `*`; или импорт из `.txt`/`.json`).
- У галереи курса могут быть дополнительные медиафайлы (видео/изображения).
- Записанные пользователи могут скачать урок целиком (HTML-файл со всей информацией: текст, медиа, тест с ответами).
